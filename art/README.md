# Mathematical art

This layer maps mathematical structure into visual, sonic, or material form while preserving a strict boundary between mathematical validity and evaluated communication impact.

| Location | Purpose |
|---|---|
| `VISUAL_ENCODING_STANDARD.md` | Normative encoding, accessibility, provenance, and impact rules |
| `design_tokens.json` | Machine-readable colors, line styles, typography, and evidence encodings |
| `svg/` | Exact vector sources owned by the project |
| `threejs/` | Future reviewed interactive three-dimensional artifacts |
| `shaders/` | Future generative rendering with declared equations and precision |
| `gallery/` | Curated artifact records and evaluation summaries |

No artwork may imply that a mathematical analogy is an observed sustainable-resilience mechanism.
