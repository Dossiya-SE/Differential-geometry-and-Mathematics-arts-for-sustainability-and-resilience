# Analytical charts — quantity-first baseline

The [radial comparison chart](analytic_radius.svg) has an exact governing formula, labeled dimensionless axes, readable curve codes, analytic crossover event and explicit nonempirical provenance. It uses the same reference fixture as the viability animation. `MSR-FIG-0007` is an **analytical mathematical example, not observed resilience data**.

Adaptation: require actual data, quantity, units, uncertainty representation, sample size and provenance for an empirical chart. Where these are absent, label the output an analytic/theoretical plot. Do not disguise an ordinal maturity ladder as continuous quantitative measurements. Reproduce using [render.mjs](../visual_suite/render.mjs).
