# Shader admission boundary

No shader has been promoted to the scientific gallery. The proposed [sphere-inversion laboratory](inversion_lab/README.md) (`MSR-FIG-0002`, `MSR-MOD-0002`) is an educational, domain-neutral WebGL2 prototype under draft review.

The Python model defines the mathematical transformation; browser diagnostics and GLSL are separate representations. The source includes an exact SVG fallback, pointwise residuals, and dependency-free Node.js tests. GPU rendering, device precision, and accessibility still require independent browser inspection before approval.

Shaders must document governing equations, coordinate system, numeric precision, device-dependent limitations, frame-time assumptions, figure provenance, accessibility, and analytical versus interpretive status. A visually compelling shader cannot establish sustainability or resilience conclusions.
