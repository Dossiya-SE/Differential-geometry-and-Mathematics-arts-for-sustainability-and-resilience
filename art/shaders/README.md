# Shader admission boundary

No shader has been promoted to the scientific gallery. Two educational artifacts are available:

- [Sphere-inversion laboratory](inversion_lab/README.md) (`MSR-FIG-0002`, `MSR-MOD-0002`) — internal mathematics verified, independent device review outstanding in issue #27.
- [Chapter 10 randomness laboratory](randomness_lab/README.md) (`MSR-FIG-0003`) — original seven-mode browser visual exploration governed by [MSR-SKILL-SR-001](../../skills/shader-randomness-scientific-visuals/SKILL.md), not a validated stochastic model.

The inversion's Python model defines its mathematical transformation. The randomness lab's JavaScript functions are educational code examples only; they do not define an accepted research model. Browser GLSL representations remain separately testable. The source includes an exact SVG fallback, pointwise residuals, and dependency-free Node.js tests. GPU rendering, device precision, and accessibility still require independent browser inspection before approval.

Shaders must document governing equations, coordinate system, numeric precision, device-dependent limitations, frame-time assumptions, figure provenance, accessibility, and analytical versus interpretive status. A visually compelling shader cannot establish sustainability or resilience conclusions.
