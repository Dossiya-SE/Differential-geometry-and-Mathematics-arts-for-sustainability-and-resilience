# Mathematical figures — geometry-first baseline

The [stereographic-projection construction](stereographic_projection.svg) specifies the unit sphere, excluded north pole, projection plane, formula and a checked point correspondence. Its orthographic screen representation **does not** preserve intrinsic distances or indicate a physical system. `MSR-FIG-0008` is a proposed domain-neutral mathematical figure.

Adaptation: declare domain/codomain, coordinate map, exceptional points, discretization, parameter values and mathematically permitted conclusions before choosing a rendering projection. Validate analytic incidences and limiting cases; do not interpret a visually projected intersection as a physical interaction without a model. Source: [render.mjs](../visual_suite/render.mjs).
