# Licensing status

No blanket open-source or open-content license has yet been selected for this repository. Until the owner adopts explicit license files, copyright remains with the respective authors and no permission beyond applicable law should be inferred.

A future licensing decision must separately address:

- software source code;
- scholarly writing and documentation;
- original mathematical artwork and figures;
- data and evidence matrices;
- third-party papers, figures, datasets, trademarks, and software.

Third-party source PDFs are not redistributed. Citations, DOIs, checksums, and lawful access links are used instead. Adding a license is a protected governance decision because code, writing, art, and data may require different terms.
