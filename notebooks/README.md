# Notebooks

Notebooks support exploration, teaching, and narrative demonstrations. Reusable algorithms must live in `src/msr/`; verification must live in `tests/`; confirmatory runs must have an experiment record.

Each admitted notebook declares its purpose, evidence status, input records, environment, seed, generated outputs, and whether all cells execute in order from a clean kernel. No application notebook is admitted while the application remains `NOT_SELECTED`, except as a labeled candidate-feasibility artifact.
