# Changelog

All material changes are recorded here. Versions follow semantic versioning for the research platform; evidence records and model contracts retain their own immutable identifiers and versions.

## 0.4.0 — 2026-08-22

### Added

- domain-neutral research-platform architecture;
- mathematical model and experiment schemas;
- Python reference package and two-sphere verification fixture;
- unit, property, numerical, and repository-regression tests;
- mathematical-art visual encoding and provenance standards;
- Quarto documentation structure;
- contribution, governance, security, and research-integrity controls;
- GitHub continuous-integration, documentation, reproducibility, citation, release, and security workflows.

### Changed

- repository identity expanded from a literature-review package to an evidence-to-publication research platform;
- `CITATION.cff` now cites the platform rather than treating the first focal paper as the preferred citation.

### Preserved

- application selection remains `NOT_SELECTED`;
- the `MSR-CA-001` ten-chain architecture remains `PROPOSED_NON_EXHAUSTIVE`;
- the existing Phase-0 literature review and Case Study MSR-CS-001 remain evidentially bounded.

## 0.3.2 — 2026-08-22

- Replaced the provisional six-chain scaffold with the ten-chain `MSR-CA-001` architecture.
